# 模型评估指标说明

## 混淆矩阵

二分类任务的预测结果可归纳为四类：

- **真阳性 TP（True Positive）**：实际恶性，预测恶性。
- **真阴性 TN（True Negative）**：实际良性，预测良性。
- **假阳性 FP（False Positive）**：实际良性，预测恶性，即误报。
- **假阴性 FN（False Negative）**：实际恶性，预测良性，即漏报。

在医学筛查场景中，**假阴性（漏诊）的代价远高于假阳性（误报）**，因为漏掉一个真正的恶性肿瘤会延误治疗。因此评估模型时不能只看准确率。

## 常用指标的计算与含义

- **准确率 Accuracy = (TP + TN) / 总数**：整体判对的比例。类别不平衡时可能产生误导。
- **精确率 Precision = TP / (TP + FP)**：预测为恶性的样本中真正恶性的比例，反映「报出来的有多准」。
- **召回率 Recall / 灵敏度 Sensitivity = TP / (TP + FN)**：实际恶性样本中被成功识别的比例，反映「恶性的有没有漏」。
- **特异度 Specificity = TN / (TN + FP)**：实际良性样本中被正确识别的比例。
- **F1 分数 = 2 × Precision × Recall / (Precision + Recall)**：精确率与召回率的调和平均，两者兼顾的综合指标。
- **ROC 曲线与 AUC**：以不同阈值绘制真正率对假正率曲线，曲线下面积 AUC 越接近 1 越好。AUC 不受阈值与类别分布影响，是评价二分类模型排序能力的稳健指标。

## 阈值选择与风险分层

预测模型输出的是恶性概率而非直接结论，需要设定阈值把概率转成类别。默认以 0.5 为界，但在筛查场景中往往**下调阈值以提高召回率**，宁可多复查也不漏诊。

本系统在概率基础上进一步划分风险等级：

- 恶性概率低于 0.35 判定为**低风险**。
- 0.35 至 0.70 之间判定为**中风险**。
- 高于 0.70 判定为**高风险**。

风险等级的作用是把连续概率转化为临床可操作的分流建议：低风险可常规随访，中风险建议短期复查或进一步影像评估，高风险建议尽快活检明确病理。

## 泛化能力与验证方法

- **交叉验证**：将数据划分为 k 折轮流训练与验证，评估结果更稳定。
- **独立测试集**：留出未参与训练的数据评估，检验真实泛化能力。
- **外部验证**：在其他医院、其他设备采集的数据上验证，检验跨中心稳健性。外部验证是医学 AI 模型落地前的必要环节。

## 本系统的评估结果

数据集共 569 例样本，其中恶性 212 例、良性 357 例。按 8:2 分层抽样划分训练集与测试集（测试集 114 例），逻辑回归模型取得约 97% 的准确率与 0.99 以上的 AUC，召回率约 95%。随机森林作为对照算法准确率约 96.5%，但单样本推理耗时约为逻辑回归的百倍以上。

需要说明的是，该数据集样本量较小且来源单一，上述指标不能直接等同于临床实际表现，仅用于教学演示。
